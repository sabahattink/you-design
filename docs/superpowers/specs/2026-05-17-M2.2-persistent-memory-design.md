# M2.2 — Persistent Memory Design

**Goal:** Replace ephemeral localStorage workspace with Postgres-backed project persistence and pgvector semantic memory, while keeping localStorage as a fast cache.

**Scope:** Named project list (no auth, single-user local instance). Auth deferred to M5 (multiplayer).

---

Add columns to the existing table:

```typescript
name: text('name').notNull().default('Untitled'),

// intentContract: already exists as jsonb
// Remove: canvasState jsonb (replaced by project_pages table)
```

### New: `project_pages` table (packages/db/src/project-pages.ts)

```typescript
export const projectPages = pgTable(
  'project_pages',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    projectId: uuid('project_id')
      .notNull()
      .references(() => projects.id, { onDelete: 'cascade' }),
    path: text('path').notNull(), // '/', '/pricing', etc.
    title: text('title').notNull(),
    html: text('html').notNull(),
    updatedAt: timestamp('updated_at').notNull().defaultNow(),
  },
  (t) => [uniqueIndex('project_pages_project_path_idx').on(t.projectId, t.path)],
);
```

### New: `project_memories` table (packages/db/src/project-memories.ts)

```typescript
export const projectMemories = pgTable('project_memories', {
  id: uuid('id').primaryKey().defaultRandom(),
  projectId: uuid('project_id')
    .notNull()
    .references(() => projects.id, { onDelete: 'cascade' }),
  summary: text('summary').notNull(),
  embedding: vector('embedding', { dimensions: 1536 }), // text-embedding-3-small
  createdAt: timestamp('created_at').notNull().defaultNow(),
});
```

### Migration

Run `drizzle-kit generate` → `drizzle-kit migrate` to produce SQL migration files. Enable pgvector extension in migration: `CREATE EXTENSION IF NOT EXISTS vector;`

## 2. API Endpoints (apps/api)

New route file: `apps/api/src/routes/projects.ts`

### Project CRUD

| Method | Path                   | Body               | Response                      |
| ------ | ---------------------- | ------------------ | ----------------------------- |
| GET    | `/api/v1/projects`     | —                  | `{ projects: ProjectMeta[] }` |
| POST   | `/api/v1/projects`     | `{ name: string }` | `{ project: ProjectMeta }`    |
| GET    | `/api/v1/projects/:id` | —                  | `{ project: ProjectFull }`    |
| PATCH  | `/api/v1/projects/:id` | `ProjectPatch`     | `{ ok: true }`                |
| DELETE | `/api/v1/projects/:id` | —                  | `{ ok: true }`                |

**Types:**

```typescript
type ProjectMeta = { id: string; name: string; pageCount: number; updatedAt: string };
type ProjectFull = ProjectMeta & {
  intentPhase: string;
  intentContract: unknown | null;
  pages: Array<{ path: string; title: string; html: string }>;
};
type ProjectPatch = {
  name?: string;
  intentPhase?: string;
  intentContract?: unknown;
  pages?: Array<{ path: string; title: string; html: string }>;
};
```

`PATCH` upserts pages: for each page in the payload, insert or update by `(projectId, path)`. Pages not in the payload are left untouched (no implicit delete — caller sends all pages).

### Memory endpoints

| Method | Path                                   | Body                                            | Response                 |
| ------ | -------------------------------------- | ----------------------------------------------- | ------------------------ |
| POST   | `/api/v1/projects/:id/memories`        | `{ summary: string; modelConfig: ModelConfig }` | `{ ok: true }`           |
| GET    | `/api/v1/projects/:id/memories/search` | `?q=<text>&modelConfig=<json>`                  | `{ memories: string[] }` |

**Memory POST flow:**

1. Call OpenAI embeddings API (`text-embedding-3-small`) with `summary`.
2. Insert row into `project_memories`.
3. If modelConfig has no OpenAI-compatible key: insert row with `embedding = null` (summary still stored, vector search skipped).

**Memory GET flow:**

1. Embed `q` using same model.
2. Query: `ORDER BY embedding <=> $queryVector LIMIT 3`.
3. If embedding is null (no OpenAI key): return last 3 summaries by `createdAt` instead.

## 4. Web Client

### 4a. Workspace Store additions (apps/web/src/lib/workspace/store.ts)

New state fields:

```typescript
projectId: string | null;        // current project DB id, null = not yet saved
projectName: string;             // display name

setProjectId: (id: string) => void;
setProjectName: (name: string) => void;
```

Add `projectId` and `projectName` to `partialize` (persisted to localStorage as fast cache).

### 4b. Project API client (apps/web/src/lib/projects/api.ts)

```typescript
export async function listProjects(): Promise<ProjectMeta[]>;
export async function createProject(name: string): Promise<ProjectMeta>;
export async function loadProject(id: string): Promise<ProjectFull>;
export async function saveProject(id: string, patch: ProjectPatch): Promise<void>;
export async function deleteProject(id: string): Promise<void>;
export async function storeMemory(
  id: string,
  summary: string,
  modelConfig: ModelConfig,
): Promise<void>;
export async function searchMemories(
  id: string,
  q: string,
  modelConfig: ModelConfig,
): Promise<string[]>;
```

All functions call `http://localhost:3001/api/v1/...`. On network error, log and continue (offline graceful degradation).

### 4c. useProjectSync hook (apps/web/src/lib/projects/useProjectSync.ts)

```typescript
export function useProjectSync(): void;
```

Behaviour:

- On mount: if `projectId` is set in store, call `loadProject(projectId)` → hydrate store (pages, intentContract, intentPhase).
- Watch store state (intentPhase, intentContract, pages) with a 1500ms debounce.
- On change: if `projectId` is set, call `saveProject(projectId, patch)`.
- If API unreachable: silently skip (localStorage still has the data).

Mounted once in `WorkspaceLayout`.

### 4d. ProjectSwitcher component (apps/web/src/components/sidebar/ProjectSwitcher.tsx)

- Displays current `projectName` at the top of the sidebar.
- Click opens a small dropdown/popover:
  - Lists all projects (name + updatedAt relative date).
  - "New project" button → prompts for name → calls `createProject` → sets projectId in store → resets workspace state.
  - Switch project → calls `loadProject` → hydrates store.
  - Rename (inline edit on double-click).
  - Delete (with confirmation).
- If no project selected (projectId is null), shows "Save project..." button that creates one with a default name.

### 4e. Project list modal (apps/web/src/components/projects/ProjectListModal.tsx)

- Shown on `/app` load when `projectId` is null.
- Lists existing projects or shows empty state.
- "New project" → name input → create → proceed to workspace.
- "Continue" with selected project → load → proceed.
- Dismissible (continues without saving — localStorage-only mode for demos).

### 4f. WorkspaceLayout changes

- Mount `useProjectSync` hook.
- Render `ProjectSwitcher` at top of sidebar (above `PageList`).
- Conditionally render `ProjectListModal` when `projectId === null && apiReachable`.

## 5. Semantic Memory Integration

### Storing memories (apps/web/src/lib/chat/designer-dispatch.ts)

After each successful `write_page` / `update_element` / `add_element`:

```typescript
void storeBuildMemory(projectId, intentContract, pagePath, finalHtml);
```

`storeBuildMemory` (apps/web/src/lib/projects/memory.ts):

1. Build a short summary string: `"Page ${path}: ${intentContract.domain} for ${intentContract.persona}. Key elements: <h1>, <section class=...>"` (extract top-level tags from HTML)
2. Call `storeMemory(projectId, summary, defaultModelConfig)`.
3. Fire-and-forget (void), never blocks designer flow.

### Recalling memories (apps/web/src/lib/chat/designer-agent.ts)

In `designerSystemPrompt(contract, memories: string[])`:

```typescript
const memoryBlock =
  memories.length > 0
    ? `\n\nProject memory (past sessions):\n${memories.map((m, i) => `${i + 1}. ${m}`).join('\n')}`
    : '';
```

Appended after the domain addendum.

In `useDesignerSend` (apps/web/src/lib/chat/useDesignerSend.ts), before building the API request:

```typescript
const memories = projectId ? await searchMemories(projectId, text, defaultModel) : [];
```

## 6. Error Handling & Graceful Degradation

| Failure                              | Behaviour                                                           |
| ------------------------------------ | ------------------------------------------------------------------- |
| API unreachable (Docker not running) | localStorage-only mode, no save attempt, no project modal           |
| Embedding API missing key            | Memory stored without vector, fallback to recency-based recall      |
| Save fails (network blip)            | Retry once after 3s, then silently drop (localStorage still intact) |
| Load fails                           | Keep localStorage data, show toast "Could not load from server"     |
