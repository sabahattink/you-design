# M2.3 — Smart Router + Cost Tracking Design

**Goal:** Route each LLM call to the cheapest capable model tier, and track + display token usage costs in real time.

**Scope:** Model tier tagging on configured models, per-agent routing, DB-persisted usage logs, session cost display in header.

---

## 1. Model Tier System

### Shared: extend `ModelConfig` (`packages/shared/src/providers.ts`)

Add one field to the existing Zod schema:

```typescript
tier: z.enum(['fast', 'standard', 'best']).default('standard'),
```

`ModelConfig` now includes `tier`. Existing persisted configs without `tier` default to `'standard'` via Zod's `.default()`.

### Shared: router utility (`packages/shared/src/router.ts`)

```typescript
export type TaskType = 'intent' | 'critic' | 'designer' | 'memory';

const TASK_TIER: Record<TaskType, 'fast' | 'standard' | 'best'> = {
  intent: 'fast',
  critic: 'fast',
  memory: 'fast',
  designer: 'standard',
};

export function selectModelForTask(
  task: TaskType,
  models: ModelConfig[],
  defaultModelId: string | null,
): ModelConfig | null {
  const tier = TASK_TIER[task];
  // Prefer exact tier match
  const match = models.find((m) => m.tier === tier);
  if (match) return match;
  // Fall back to default model
  if (defaultModelId) return models.find((m) => m.id === defaultModelId) ?? null;
  return models[0] ?? null;
}
```

### Web: use router in agents

Replace `selectActiveModel(s)` with `selectModelForTask(task, s.models, s.defaultModelId)` in:

- `useDesignerSend.ts` → task: `'designer'`
- `ChatPanel.tsx` (intent phase) → task: `'intent'`
- `critic-dispatch.ts` → task: `'critic'`
- `memory.ts` / `useDesignerSend.ts` memory recall → task: `'memory'`

### Web: UI tier badges

**`ModelPicker.tsx`:** Show tier badge next to each model in dropdown:

```
[ Claude Haiku  fast ] ←
  Claude Sonnet std
  Claude Opus   best
```

**`ProviderConfig.tsx`:** Add tier `<select>` (Fast / Standard / Best) when adding or editing a model.

## 2. Cost Tracking

### Shared: price table (`packages/shared/src/pricing.ts`)

```typescript
export type PricingEntry = { inputPer1M: number; outputPer1M: number };

export const MODEL_PRICING: Record<string, PricingEntry> = {
  // Anthropic
  'claude-haiku-4-5': { inputPer1M: 0.8, outputPer1M: 4.0 },
  'claude-haiku-4-5-20251001': { inputPer1M: 0.8, outputPer1M: 4.0 },
  'claude-sonnet-4-5': { inputPer1M: 3.0, outputPer1M: 15.0 },
  'claude-sonnet-4-6': { inputPer1M: 3.0, outputPer1M: 15.0 },
  'claude-opus-4-7': { inputPer1M: 15.0, outputPer1M: 75.0 },
  // OpenAI
  'gpt-4o-mini': { inputPer1M: 0.15, outputPer1M: 0.6 },
  'gpt-4o': { inputPer1M: 2.5, outputPer1M: 10.0 },
  'gpt-4.1-mini': { inputPer1M: 0.4, outputPer1M: 1.6 },
  'gpt-4.1': { inputPer1M: 2.0, outputPer1M: 8.0 },
  // Google
  'gemini-1.5-flash': { inputPer1M: 0.075, outputPer1M: 0.3 },
  'gemini-1.5-pro': { inputPer1M: 3.5, outputPer1M: 10.5 },
  'gemini-2.0-flash': { inputPer1M: 0.1, outputPer1M: 0.4 },
};

export function estimateCost(
  modelName: string,
  promptTokens: number,
  completionTokens: number,
): number | null {
  const entry = MODEL_PRICING[modelName];
  if (!entry) return null;
  return (
    (promptTokens / 1_000_000) * entry.inputPer1M +
    (completionTokens / 1_000_000) * entry.outputPer1M
  );
}
```

### DB: `usage_logs` table (`packages/db/src/schema/usage-logs.ts`)

```typescript
export const usageLogs = pgTable('usage_logs', {
  id: uuid('id').primaryKey().defaultRandom(),
  projectId: uuid('project_id').references(() => projects.id, { onDelete: 'set null' }),
  agent: text('agent').notNull(), // 'intent' | 'designer' | 'critic' | 'memory'
  modelName: text('model_name').notNull(),
  promptTokens: integer('prompt_tokens').notNull().default(0),
  completionTokens: integer('completion_tokens').notNull().default(0),
  estimatedCostUsd: numeric('estimated_cost_usd', { precision: 10, scale: 6 }),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});
```

### API: usage route (`apps/api/src/routes/usage.ts`)

```
POST /api/v1/usage
  Body: { projectId?: string; agent: string; modelName: string;
          promptTokens: number; completionTokens: number }
  Action: calculate estimatedCostUsd via estimateCost(), insert row
  Response: { ok: true; estimatedCostUsd: number | null }

GET /api/v1/usage?projectId=<uuid>&limit=50
  Response: { logs: UsageLog[] }  — ordered by createdAt DESC
```

### Web: capture usage in `streamLlm` client (`apps/web/src/lib/llm/client.ts`)

The finish event already arrives as `{ finishReason, usage: { promptTokens, completionTokens } }`. The client currently yields it as-is. Add an optional `onUsage` callback parameter:

```typescript
export async function* streamLlm(
  params: StreamParams,
  onUsage?: (usage: { promptTokens: number; completionTokens: number }) => void,
): AsyncGenerator<StreamEvent>
```

When a finish event with usage arrives, call `onUsage(usage)`.

### Web: workspace store additions

New state:

```typescript
sessionCostUsd: number;        // running total, resets on page reload
appendSessionCost: (delta: number) => void;
```

Not persisted to localStorage — intentionally ephemeral (session only).

### Web: fire usage log after each LLM call

In `useDesignerSend.ts`, `ChatPanel.tsx` (intent), and `critic-dispatch.ts`, pass `onUsage` to `streamLlm`:

```typescript
onUsage = async ({ promptTokens, completionTokens }) => {
  const cost = estimateCost(activeModel.modelName, promptTokens, completionTokens);
  if (cost !== null) appendSessionCost(cost);
  // fire-and-forget log to API
  void fetch('http://localhost:3001/api/v1/usage', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      projectId: projectId ?? undefined,
      agent,
      modelName: activeModel.modelName,
      promptTokens,
      completionTokens,
    }),
  }).catch(() => {});
};
```

## 4. Error Handling

| Failure                       | Behaviour                                              |
| ----------------------------- | ------------------------------------------------------ |
| Usage log POST fails          | Silent — `catch(() => {})`, session cost still updates |
| Model not in PRICING table    | `estimateCost` returns null, display "?" in UI         |
| No fast-tier model configured | Router falls back to default model                     |
| DB insert fails               | Log error server-side, return 500 (client ignores)     |
